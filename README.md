# NSMBW Route Editor

A tool to help with New Super Mario Bros. Wii RouteInfo file editing.

## Introduction

This web app was made to help with the process of editing the RouteInfo file of New Super Mario Bros.
Wii's world maps. While the files contained within the RouteInfo file are just plain CSV files, a lot
of the technicalities come from predefined strings not many people are aware of. This tool helps with
making this process more user-friendly by preventing said errors from happening during the editing
process instead of figuring them out during playtesting.

This tool is available under https://b1here.github.io/route-editor
